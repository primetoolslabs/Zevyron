# ZEVYRON 3.0 — Intelligent Core

## Core flow
**Analyze → Explain → Recommend → Protect → Execute → Measure → Undo**

## Rules
- Never fabricate FPS, temperature, latency, health, performance, or hardware values.
- Show unavailable when a real sensor/source cannot provide a metric.
- Automatic recommendations must exclude advanced/high-risk operations.
- Save previous state before every reversible change.
- Record an operation as applied only after successful execution.
- Protect Defender, Firewall, security updates and critical Windows services by policy.
- Explain why every recommendation applies to the current machine.
- Before/after reports must use measured values.
- Let the user review recommendations before applying.
- Keep a local auditable history and rollback information.

installer/updater tests, rollback tests, translation review, and a clean release pipeline.
