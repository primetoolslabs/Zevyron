# Zevyron 2.24.3

Versão criada para validar o sistema de atualização automática.

## Teste esperado

1. Manter o Zevyron 2.24.2 instalado.
2. Publicar a tag `v2.24.3`.
3. Abrir o Zevyron 2.24.2.
4. Verificar a nova versão.
5. Baixar a atualização.
6. Usar **Reiniciar e instalar**.
7. Confirmar que a versão instalada passou para **2.24.3** sem desinstalar manualmente.

Mensagem de validação: **Sistema de atualização ativo**.
