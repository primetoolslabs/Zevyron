# Zevyron 3.0.0-beta.18 — Report Center + Profile Backup

## Report Center
- Nova aba Relatórios.
- Diagnóstico consolidado de Windows, CPU, RAM, GPU, armazenamento, bateria, rede resumida e Safety Engine.
- Exportação em JSON para análise estruturada.
- Exportação em Markdown para suporte/documentação.
- Métricas ausentes permanecem indisponíveis.
- Privacidade por padrão: hostname, usuário, IP, MAC, serial, UUID e caminhos pessoais são excluídos.

## Backup de Perfil
- Exporta somente preferências úteis.
- Importa idioma, tema, perfil, sidebar, animações, preferências de Apps, bandeja e canal de atualização.
- Não exporta notificações, logs, histórico do Safety Engine, snapshots, caches, diagnóstico ou nome do usuário.
- Importação exige confirmação e recarrega a interface para aplicar preferências.

## Preservação
Esta versão é construída por cima da beta.6. First Run Wizard, Notification Center, ajuda integrada,
Network Center, Hardware Monitor, Startup Manager, Smart Cleanup, PC Health, Recovery Center,
Safety Engine 2.0, Game Mode, Debloat, DNS, Apps, Backup, Utilities, Settings e About permanecem.
