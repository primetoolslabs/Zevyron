# Zevyron 3.0.0-beta.21 — First Run Wizard + Notifications + Integrated Help

## First Run Wizard
- Substitui a antiga pergunta única por um assistente em quatro etapas.
- Escolha de idioma.
- Perfil inicial: Uso diário, Gaming, Notebook/Bateria ou Desempenho.
- Criação opcional/recomendada de ponto de restauração usando o mecanismo já existente.
- Opção de abrir PC Health ao concluir.
- Nenhuma otimização é aplicada automaticamente durante o assistente.

## Central de Notificações
- Nova aba de notificações locais.
- Registra eventos de Game Mode, atualizações e operações de aplicativos.
- Contador de não lidas no menu.
- Marcar como lida, marcar todas e limpar histórico.
- Persistência em localStorage, sem envio de telemetria.

## Ajuda Integrada
- O botão antigo Docs dos tweaks foi substituído por Ajuda funcional.
- Mostra descrição, categoria, classificação do Safety Engine, reversibilidade,
  reinicialização, compatibilidade, motivos da classificação e avisos.
- Mantém todos os mecanismos de aplicação/reversão existentes.

## Preservação
A beta.6 é construída de forma aditiva sobre a beta.5. Network Center, Hardware Monitor,
Startup Manager, Smart Cleanup, PC Health, Recovery Center, Safety Engine 2.0, Game Mode,
Debloat, DNS, Apps, Backup, Utilities, Settings e About permanecem presentes.
