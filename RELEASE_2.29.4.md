# Zevyron 3.0.0 Stable

Reorganização do Debloat Windows sem remover funcionalidades.

- Remove a aba separada **Debloat+** do menu lateral.
- Mantém o mecanismo e a página interna de Debloat.
- O card **Debloat Windows** dentro de **Otimizações** passa a abrir a ferramenta de Debloat.
- Mantém Safety Engine, Game Mode, monitoramento, restauração, atualizador, multilíngue e demais funções inalteradas.
- Mantém a validação de sincronização entre a tag do GitHub e o `package.json`.
